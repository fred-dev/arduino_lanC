# arduino_lanC

Arduino LANC remote for video cameras: buttons for record, zoom in/out and focus near/far, sent to the camera's LANC (Canon: "REMOTE") port.

Based on Martin Koch's *Simple LANC Remote* (2011) and tested with a Canon XF300. The interface circuit is described [here](http://controlyourcamera.blogspot.com/2011/02/arduino-controlled-video-recording-over.html). `LANC Documenation/` has reference notes on the LANC protocol.

Old code, kept for reference.
